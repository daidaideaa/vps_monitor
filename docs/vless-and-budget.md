# VLESS 迁移与监控流量口径

2026-09-27：VMISS 新增 VLESS + TCP + TLS + Vision，HY2 保留备用。Windows 独立探针与日常客户端分开记录；旧 HY2 记录不得改名为 VLESS。服务端日志按对应协议关联。停止旧探针只结束观测，不证明恢复。

常规采样和成功批量上报改为 300 秒，额外新会话测试关闭。首次失败最多两次复核，间隔 5 秒；恢复需两次成功。电脑关闭时仅 Windows 路径缺测，VMISS 库存、日报及服务端探针继续运行。缺测不能计作丢包。

## 流量

旧实现将不足一天的运行时间按一天计算，导致首日月外推偏低。现按实际观察时长（最低 60 秒防止启动瞬间除零）外推，未满一天属于暂估。

- **实计**：压缩上传请求体加响应体。不是网卡或商家计费字节，不含 TLS、TCP、探测及邮件流量。
- **估算**：每次 ICMP 256 B、TCP/DNS 2048 B、HTTPS 8192 B；加两处各 150 MiB/月的开销预留。这是模型，不是实测。
- **300 秒新计划**：Windows 每轮 19200 B，VMISS 每轮 10240 B；全天运行 30 天共约 254 MB，加 315 MB 预留及约 20 MB 上传，约 **0.59 GB/月**，占 400 GB 约 **0.15%**。异常复核、公开访问量和 Telegram 等会影响结果，目标仍需实测校准。
- **历史月外推**保留从原观察起点累计的数据，包含此前更高频率和旧目标，不能当作新配置的稳定预测。页面明确标注观察时间和口径。
- VPS 网卡累计含日常 VPN，不当作监控专用流量，也不当作剩余额度。

Cloudflare 仅提供静态页面及 60～300 秒缓存的白名单公开摘要，无监控 DO 读写，不启用付费套餐。不进行测速文件下载或**定期**商家网页轮询；2026-10-09 新增的单次 VMISS 年付订单进程仅在首次检查及有效的新补货信号后访问官网核对库存，详见 [订单说明](vmiss-reservation.md)。
