# 故障演练报告 · 2026-09-27

## 已验证

在 Linux 上用临时回环 HTTP 源站、HY2 服务与客户端执行真实请求，临时证书只在测试目录存在。没有改防火墙、没有重启业务代理，没有把测试库存或合成采样写入生产看板。

| 项目 | 结果 |
|---|---|
| 独立 HY2 基线 | HTTP 204，约 7.6 ms |
| UDP 黑洞 | 18 个 UDP 数据报到达丢弃进程，3 次 HY2 请求均失败 |
| 故障与恢复 | 3 次失败后告警入队，2 次成功后恢复入队 |
| 前后证据 | 保存此前 600 秒、后续 300 秒；时间窗由明确标记的加速时钟模拟 |
| DNS 失败 | `.invalid` 域名实际解析失败，记录异常类型 |
| 服务退出 | 独立进程退出，触发服务异常取证 |
| 上传失败 | HTTP 503 不丢本地样本；服务恢复后按原采样时间重传 |
| 探针离线 | 空观测不会增加链路失败次数 |
| Linux UDP 元数据 | 内核 BPF 限定端口，能捕获目标头部，过滤其他端口，不持久化测试载荷 |
| 私有读取 | 未登录访问页面、latest、history、incidents、evidence 返回 401 |
| Access 验证 | 本地 RSA 签名测试覆盖 issuer / audience / email / expiry / 错误签名与预览主机 |
| 数据隔离 | 来源令牌不能提交其他来源；公开 v3 白名单剔除嵌套私有字段 |
| 库存回放 | 历史静默、编辑售罄、重复去重、地区/PID 排除、过期码、优惠单独更新、通知渠道独立重试 |
| 页面 | 公开页面读取四款 v3 状态；私有原生页面使用本机真实缓存验证曲线、客户端选择与时间线 |
| 邮件 | Windows SSL 465 和 VMISS STARTTLS 587 真实测试邮件发送成功 |

代码测试：Python 新旧集成 58 项、旧独立库存模块 45 项、Worker/页面 Node 测试 23 项均在 Linux CI 通过（合计 126 项）。旧模块的 POSIX 文件权限断言在 Windows 不适用，已在 Linux 验证，没有删掉该权限检查。

## 诊断边界

单次超时、中间跳不回 ICMP、单侧日志不足以确认运营商故障。报告展示事实、推断和缺失证据。部署前或延迟下发的故障不能补造当时 UDP 元数据；会保留仍可获得的同窗日志并明确说明缺口。
